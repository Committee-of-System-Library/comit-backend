NightSnackApplicationControllerApi

인터페이스 기반으로 추출한 엔드포인트 문서입니다.

야식 마차 선착순 신청 POST /night-snacks/{nightSnackId}/applications 내 티켓 조회 GET /night-snacks/{nightSnackId}/my-ticket 날짜별 야식 마차 단건 조회 GET /night-snacks 학생회비 납부 여부 조회 GET /night-snacks/student-council-fee
POST

야식 마차 선착순 신청

지정한 야식 마차에 선착순 신청합니다. 신청 성공 시 QR 수령 티켓 토큰과 신청 순번을 반환합니다. 동일 야식 마차에 1인 1회만 신청할 수 있습니다.

POST/night-snacks/{nightSnackId}/applications

경로 변수

필드명 타입 필수 여부 설명
nightSnackId Long required 신청할 야식 마차 ID입니다.

응답 바디 필드

필드명 타입 필수 여부 설명
remaining int optional 응답 시점의 잔여 수량입니다.
sequence int optional 몇 번째 신청자인지를 나타내는 순번입니다.
ticketToken String optional QR 수령 티켓 값입니다.

에러 응답 필드

필드명 타입 필수 여부 설명
type String required 문제 유형을 식별하는 URI path입니다.
title String required HTTP 상태를 요약한 제목입니다.
status Integer required HTTP 상태 코드입니다.
detail String required 클라이언트에 노출할 에러 설명입니다.
instance String required 에러가 발생한 요청 경로입니다.
errorCode String required 프론트엔드 분기에 사용하는 안정적인 에러 코드입니다.
invalidFields List<ProblemFieldViolation> optional validation 에러에서만 포함됩니다. 필드명과 검증 메시지 목록입니다.
errorTrackingId String optional 서버 내부 오류에서만 포함됩니다. 로그 추적용 식별자입니다.
timestamp OffsetDateTime required 에러 응답 생성 시각입니다.

에러 코드

errorCode HTTP 상태 type detail 발생 조건
UNAUTHORIZED 401 /problems/common/unauthorized 인증이 필요합니다. 인증 정보가 없거나 유효한 회원을 식별할 수 없을 때
EVENT_NOT_FOUND 404 /problems/night-snack/not-found 존재하지 않는 야식 마차입니다. 존재하지 않는 야식 마차 ID로 요청할 때
EVENT_NOT_OPEN 409 /problems/night-snack/not-open 신청 가능한 상태가 아닙니다. 아직 오픈되지 않았거나 마감된 야식 마차에 신청할 때
EVENT_SOLD_OUT 409 /problems/night-snack/sold-out 마감되었습니다. 정원이 모두 소진되어 마감되었을 때
ALREADY_APPLIED 409 /problems/night-snack/already-applied 이미 신청한 야식 마차입니다. 이미 신청한 야식 마차에 다시 신청할 때

응답 예시

{
  "result" : "SUCCESS",
  "data" : {
    "ticketToken" : "9f1c2e4a-7b8d-4c2a-9e3f-1a2b3c4d5e6f",
    "sequence" : 37,
    "remaining" : 63
  }
}

에러 예시

{
  "type" : "/problems/common/unauthorized",
  "title" : "Unauthorized",
  "status" : 401,
  "detail" : "인증이 필요합니다.",
  "instance" : "/night-snacks/{nightSnackId}/applications",
  "errorCode" : "UNAUTHORIZED",
  "timestamp" : "2026-03-24T03:10:00Z"
}

내 티켓 조회

로그인한 사용자가 지정한 야식 마차에 신청한 티켓 정보를 조회합니다. ticketToken을 QR 코드로 렌더링해 수령 시 제시합니다.

GET/night-snacks/{nightSnackId}/my-ticket

경로 변수

필드명 타입 필수 여부 설명
nightSnackId Long required 조회할 야식 마차 ID입니다.

응답 바디 필드

필드명 타입 필수 여부 설명
applicationId Long optional 신청 ID입니다.
appliedAt LocalDateTime optional 신청 시각입니다.
confirmedAt LocalDateTime optional 수령 확인 시각입니다. 미수령 시 null입니다.
menu String optional 제공 메뉴입니다.
nightSnackDate LocalDate optional 야식 마차 날짜입니다.
pickupDeadline LocalDateTime optional 수령 마감 시각입니다.
pickupLocation String optional 수령 장소입니다.
status NightSnackApplicationStatus optional 티켓 상태입니다. (PENDING / CONFIRMED / NO_SHOW)
ticketToken String optional QR 수령 티켓 값입니다.

에러 응답 필드

필드명 타입 필수 여부 설명
type String required 문제 유형을 식별하는 URI path입니다.
title String required HTTP 상태를 요약한 제목입니다.
status Integer required HTTP 상태 코드입니다.
detail String required 클라이언트에 노출할 에러 설명입니다.
instance String required 에러가 발생한 요청 경로입니다.
errorCode String required 프론트엔드 분기에 사용하는 안정적인 에러 코드입니다.
invalidFields List<ProblemFieldViolation> optional validation 에러에서만 포함됩니다. 필드명과 검증 메시지 목록입니다.
errorTrackingId String optional 서버 내부 오류에서만 포함됩니다. 로그 추적용 식별자입니다.
timestamp OffsetDateTime required 에러 응답 생성 시각입니다.

에러 코드

errorCode HTTP 상태 type detail 발생 조건
UNAUTHORIZED 401 /problems/common/unauthorized 인증이 필요합니다. 인증 정보가 없거나 유효한 회원을 식별할 수 없을 때
APPLICATION_NOT_FOUND 404 /problems/night-snack/application-not-found 신청 내역이 없습니다. 해당 야식 마차에 신청 내역이 없을 때

날짜별 야식 마차 단건 조회

날짜(yyyy-MM-dd)로 야식 마차 정보를 조회합니다. 인증 없이 호출 가능합니다. openAt을 이용해 클라이언트 카운트다운 타이머를 구성할 수 있습니다.

GET/night-snacks

쿼리 파라미터

date LocalDate required 조회할 야식 마차 날짜입니다. (yyyy-MM-dd)

응답 바디 필드

capacity int optional -
closeAt LocalDateTime optional 신청 마감 시각입니다.
contents String optional -
menu String optional -
nightSnackDate LocalDate optional -
nightSnackId Long optional 야식 마차 ID입니다.
openAt LocalDateTime optional 신청 오픈 시각입니다. 클라이언트 카운트다운 기준으로 사용합니다.
pickupDeadline LocalDateTime optional -
pickupLocation String optional -
remaining int optional -
requiresStudentCouncilFee boolean optional 학생회비 납부 여부 신청자격입니다.
reservedCapacity int optional -
reservedRemaining int optional -
status NightSnackStatus optional 야식 마차 상태입니다. (SCHEDULED / OPEN / CLOSED)
title String optional -

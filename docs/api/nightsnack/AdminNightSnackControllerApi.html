야식 마차 생성

관리자가 선착순 야식 마차를 생성합니다. 생성 직후 상태는 SCHEDULED이며, 별도 오픈 요청으로 신청을 받기 시작합니다. 사전신청 예약분은 전체 정원의 10%(서버 정책)로 자동 계산됩니다.

POST/admin/night-snacks

요청 바디 필드

필드명 타입 필수 여부 설명
capacity int optional 전체 정원입니다. 1 이상의 정수입니다.
closeAt LocalDateTime required 신청 마감 시각입니다. openAt 이후여야 합니다. (yyyy-MM-ddTHH:mm:ss)
contents String optional 야식 마차 안내 내용입니다. 생략 가능합니다.
menu String optional 제공 메뉴입니다. 생략 가능합니다. (최대 500자, 예: 떡볶이, 순대)
nightSnackDate LocalDate required 야식 마차 날짜입니다. (yyyy-MM-dd)
openAt LocalDateTime required 신청 오픈 시각입니다. (yyyy-MM-ddTHH:mm:ss)
pickupDeadline LocalDateTime optional 수령 마감 시각입니다. 신청 마감(closeAt)과 별개로 현장 수령 가능 시각 상한입니다. 생략 가능합니다. (yyyy-MM-ddTHH:mm:ss)
pickupLocation String optional 수령 장소입니다. 생략 가능합니다. (최대 200자)
requiresStudentCouncilFee boolean optional 신청자격 — 학생회비 납부 여부입니다. 생략 시 false(자격 제한 없음)입니다.
title String optional 야식 마차 제목입니다. 생략 가능합니다. (최대 200자)

응답 바디 필드

필드명 타입 필수 여부 설명
nightSnackId Long optional 생성된 야식 마차 ID입니다.

invalidFields List<ProblemFieldViolation> optional validation 에러에서만 포함됩니다. 필드명과 검증 메시지 목록입니다.

PATCH

야식 마차 신청 오픈

PATCH/admin/night-snacks/{nightSnackId}/open

필드명 타입 필수 여부 설명
nightSnackId Long required 오픈할 야식 마차 ID입니다.

POST

사전신청(예약분) 등록

관리자가 학번 목록을 받아 예약분에 사전신청을 미리 등록합니다(요구사항 4-3). Comit 계정이 없는 학번(편입생·초과학기 등)도 등록할 수 있습니다. 멱등하게 동작하여 이미 등록된 학번은 건너뛰고, 신규 학번만 예약 잔여분에서 차감합니다. 신규 학번 수가 예약 잔여분을 넘기면 전체가 거부됩니다. 선착순 오픈 전(SCHEDULED) 상태에서만 등록할 수 있습니다.

POST/admin/night-snacks/{date}/reservations

경로 변수

필드명 타입 필수 여부 설명
date LocalDate required 사전신청을 등록할 야식 마차 날짜입니다. (yyyy-MM-dd)

요청 바디 필드

필드명 타입 필수 여부 설명
studentNumbers List<String> required 등록할 학번 목록입니다. 공백/중복은 자동 정리됩니다.

응답 바디 필드

필드명 타입 필수 여부 설명
registered int optional 이번에 신규로 등록된 수입니다.
requested int optional 중복 제거 후 요청된 학번 수입니다.
skipped int optional 이미 등록되어 건너뛴 수입니다.
tickets List<ReservedTicket> optional 신규 등록된 사전신청자의 티켓 목록입니다.

에러 응답 필드

필드명 타입 필수 여부 설명
type String required 문제 유형을 식별하는 URI path입니다.
title String required HTTP 상태를 요약한 제목입니다.
status Integer required HTTP 상태 코드입니다.
detail String required 클라이언트에 노출할 에러 설명입니다.
instance String required 에러가 발생한 요청 경로입니다.
errorCode String required 프론트엔드 분기에 사용하는 안정적인 에러 코드입니다.
invalidFields List<ProblemFieldViolation> optional validation 에러에서만 포함됩니다. 필드명과 검증 메시지 목록입니다.
errorTrackingId String optional 서버 내부 오류에서만 포함됩니다. 로그 추적용 식별자입니다.
timestamp OffsetDateTime required 에러 응답 생성 시각입니다.

에러 코드

UNAUTHORIZED 401 /problems/common/unauthorized 인증이 필요합니다. 인증 정보가 없거나 유효한 회원을 식별할 수 없을 때
INVALID_REQUEST 400 /problems/common/invalid-request 입력값이 올바르지 않습니다. 학번 목록이 비어 있거나 유효한 학번이 하나도 없을 때
FORBIDDEN 403 /problems/common/forbidden 접근 권한이 없습니다. 관리자 권한이 없는 사용자가 요청할 때

RESERVATION_NOT_ALLOWED 409 /problems/night-snack/reservation-not-allowed 사전신청은 오픈 전(SCHEDULED) 상태에서만 가능합니다. 오픈 전(SCHEDULED) 상태가 아닌 야식 마차에 사전신청할 때
RESERVED_CAPACITY_EXCEEDED 409 /problems/night-snack/reserved-capacity-exceeded 예약 가능 인원을 초과했습니다. 신규 학번 수가 예약 잔여분을 초과할 때
